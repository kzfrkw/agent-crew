# 骨格(GUI・フェーズ2)

構造は `docs/structure.md`。

## ナビゲーション

- 共通ヘッダー: 左にロゴ(`/` へ)、プロジェクトのセレクト(S5 へ)。右に接続状態(● 接続中 / ○ 再接続中)と「読み取り専用」
- 詳細画面の上部にパンくず(`プロジェクト / #12 タイトル / 実行 #45`)
- 対応待ち(F1)の件数は、ブラウザのタブのタイトルにも出す(`(2) agent-crew`)。タブを開きっぱなしにする使い方のため

## S1 ダッシュボード

対応待ちと実況を同じ重さで、左右に並べる(狭い画面では縦に積む)。

```
┌ agent-crew ── [プロジェクト▼] ─────────────────── ● 接続中  読み取り専用 ┐
│                                                                          │
│ ┌ 対応待ち (2) ───────────────────┐ ┌ 実況 ────────────────────────────┐ │
│ │ ◆計画の承認待ち  #12 在庫0を除外 │ │ ● #13 implementer (sonnet) 3分12秒│ │
│ │   plan.md を読む                 │ │   Bash: npm test                 │ │
│ │   $ agent-crew task approve 12 ⧉│ │ ────────────────────────────────── │ │
│ │ ◆回答待ち      #9 検索を追加    │ │ 10:21 #13 tool_use  Edit src/a.ts │ │
│ │   「APIの形はAとBどちら?」      │ │ 10:21 #13 発言  テストを追加します│ │
│ │   $ agent-crew task answer 9 ⧉ │ │ 10:20 #12 状態  計画中→承認待ち    │ │
│ │ (なければ「対応待ちはありません」)│ │ …(最新が上、最大50件)            │ │
│ └──────────────────────────────────┘ └────────────────────────────────────┘ │
│                                                                          │
│ タスク  [すべて|進行中|対応待ち]  □ 完了・取り消しも表示                  │
│ ┌ shop ──────────────────────────────────────────────────────────────┐   │
│ │ #13 ● 実装中   検索を追加        implementer  差戻し0  10:21        │   │
│ │ #12 ◆ 承認待ち 在庫0を除外       -            差戻し0  10:20        │   │
│ └────────────────────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────────┘
```

## S2 タスク詳細

```
shop / #12
#12 在庫0を除外                                          [計画の承認待ち]
 計画 ● ─ 承認 ◆ ─ 実装 ○ ─ レビュー ○ ─ QA ○ ─ 最終確認 ○ ─ 統合 ○ ─ 完了 ○
┌ 対応が必要です ─────────────────────────────────────────────────────┐
│ 計画を確認して承認してください  plan.md を読む                      │
│ $ agent-crew task approve 12 --kind plan  ⧉                         │
└─────────────────────────────────────────────────────────────────────┘
┌ 左(主)───────────────────────────────┐ ┌ 右(補助)──────────────┐
│ 成果物                                 │ │ 費用 $0.18 / 時間 1分40秒│
│  plan       ready     10:20  →         │ │ worktree                 │
│  review     approve   10:31  →         │ │  [main] …/wt/12  ac/12-x │
│ 実行                                   │ │ 承認                     │
│  #44 planner  sonnet 成功 ready $0.09 →│ │  計画 ✓ abc123           │
│  #45 implementer … 実行中 ●          →│ │  レビュー ✗ 失効         │
│ アクティビティ(このタスクのイベント)   │ │ チケット本文             │
│  10:20 状態 計画中 → 計画の承認待ち    │ │  (折りたたみ)            │
│  …                                     │ │                          │
└────────────────────────────────────────┘ └──────────────────────────┘
```

- 実行中ならバナー「エージェントが実行中です。worktree を触らないでください」
- `human_working` ならバナー「人が作業中です」と `task return` のコマンド

## S3 成果物ビューア

```
shop / #12 / plan.md
plan.md  [ready]   実行 #44 planner(sonnet) 10:20     生ファイル ↗
──────────────────────────────────────────────
(Markdown を整形して表示。frontmatter は上のバッジに置き換えて本文から外す)
```

- 同じタスクの成果物を左の細いリストで切り替えられる(狭い画面では上部のセレクト)
- 画像はそのまま、`.patch` などは等幅で表示

## S4 実行ログ

```
shop / #12 / 実行 #45
#45 implementer  sonnet  ● 実行中 3分12秒      費用 - / 判定 -
要約: (終了後に表示)   エラー: (あれば赤字)   生ログ stream.jsonl ↗
──────────────────────────────────────────────
10:21:03  ⚙ 開始  model=sonnet tools=Read,Edit,Bash
10:21:05  💬 テストを先に追加します
10:21:06  ▸ Edit  src/items.test.ts                     [開く]
10:21:09  ▸ Bash  npm test                              [開く]
            └ 結果(失敗) 1 failed …                    (折りたたみ)
…  [最新に追従 ✓]
```

- ツール実行と結果は対にして、既定は1行に畳む
- 実行中は下に追記し、「最新に追従」がオンなら自動でスクロールする
